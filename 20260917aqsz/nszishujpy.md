# 【生活】这个水果浑身都是宝，有助于降血糖、降血脂、还减少血栓形成

> 更新时间：2026-09-17 (UTC+8)

****
每年中秋前后，正是柚子成熟的季节，硕大的果实挂满枝头，满树金黄，飘香诱人。过去作为团圆夜的应景水果，中国人在其他时节也是非常喜欢柚子的，特别是南方人，吃柚子几乎成为一种习惯。
这其中大概有两个原因，第一当然是柚子的口味酸甜可口，富有多种营养成分及养生功效，人们自然愿意将其作为常备水果。

第二可能源于柚子的名称，与“佑”和 “有”同音，民间认为是大佑大有，可去除来年的霉运，非常吉祥、吉利，所以常吃柚子就变得很必要啦。

柚子小常识
柚子。又名文旦、栾、抛、团圆果等。芸香科。常绿灌木。叶大而厚，叶翼大，呈心脏型。花大，常簇生成总状花序。果实大，圆形、扁圆形或阔倒卵形；成熟时呈淡黄色或橙色。

果皮厚，有大油腺，不易剥离。果肉白色或红色，隔分成瓣，券间易分离。果味酸甜适口。秋末成熟。耐贮藏。我国广西、福建浙江、广东、四川和湖南等地均有栽培。果实可供生食或加工，果皮可制蜜饯。花、叶、果皮均可提芳香油。

柚子入药用途多
柚子是非常著名的药用植物，其果肉、果皮、花、叶核、根等均可入药，且各有不同的疗效，可谓“**浑身是宝**”。

中医认为，**柚子果肉**味甘酸、寒性，有止咳平喘、润肺清肠、健脾消食等功效，可治疗食欲不振、消化不良等症；

**柚子皮**又名橘红，风干后可作药材，味辛甘苦、性温。有理气化痰、散寒燥湿等功效，主治胸闷气滞、胃痛、咳嗽气喘等症；

**柚子花**味辛甘苦，性温，功效和作用与柚子皮类似，可用于行气、祛痰、止痛等病症的治疗，也有生发润燥之效；

**柚子叶**味辛性温，多用于风湿性关节炎、头痛及腹痛的治疗；

**柚子根、柚子核**皆味辛性温，用于顺气止痛的效果良好。

现在医学通过对袖子成分的研究发现，柚子具有以下功效：

1降血糖，降血脂
柚子果肉中含有非常丰富的维生素C、维生素P以及类胰岛素成分，可用于高血压、糖尿病、血管硬化等疾病的辅助治疗。

2降低血液粘稠度，减少血栓形成
柚子中还含有生理活性物质皮甙，可用于脑血栓、中风等疾病的预防和辅助治疗。

3减肥
由于柚子含有丰富的膳食纤维，对于降低胆固醇有显著效果，所以常吃袖子也有非常显著的减脂功效。

食用柚子有禁忌
柚子有很高的药用价值，但食用时也有禁忌。**柚子属于寒性水果**，每次食用不宜过多。患有肾结石的患者也不宜过多食用柚子，因为柚子中丰富的维生素C可能会增加肾结石的危险。而肠胃偏寒及腹泻的患者则不宜食用柚子。

另外，服药期间不宜吃柚子或喝柚子汁。因为柚子含有的活性物质对肠道有一定抑制作用，会干扰药物的正常代谢，使血液中的药物浓度高于正常值，某些情况下还会引发肝肾中毒。

目前已经证实不能与柚子汁同服的药物有：冠心病用药、降血脂药、抗过敏药、消化系统常用的西沙必利以及含咖啡因的解热镇痛药物等。

【做法】水煎服

【做法】水煎服。

柚子美食DIY
**蜂蜜柚子茶**

**材料**

1. 柚子一个

2. 冰糖，大约为柚子重量的20%左右

3. 蜂蜜，大约为柚子重量的50%左右

4. 清水若干

**做法**

1. 柚子清洗干净后剥开，分离果皮、肉、瓤。

2. 将果肉用搅拌机打成果泥，柚子皮切成细丝，果瓤留下适量切丁（果瓤越多越苦）。

3. 把处理好的柚子放入干净无油的锅中，加清水适量，大火煮沸。之后调制文火，放入冰糖，煮至有粘稠感即可。离火冷却。

4. 温热（60℃以下）时。将蜂蜜加入拌匀。

5. 把成品倒入密封玻璃瓶内，晾凉后放入冰箱保存。

挑选柚子的小技巧
袖子的好坏，不剥开厚厚的果皮亲口品尝。都难下定论，颇有点“赌石”的味道。不过还是有些技巧可以遵循，以提高选购的准确度。

观：外形均匀，上尖下宽，表皮薄而光润，毛孔细小，色泽呈淡绿或淡黄为上品。

掂：较重者说明汁多肉厚，食用起来口感较好。

闻：成熟的柚子，芳香浓郁。

压：新鲜的柚子弹性较好，按上去柔软有弹性。
